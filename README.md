# SPA Application - WB Analytics Dashboard

Vue 3 SPA приложение для анализа данных из Wildberries API с расширенной аналитикой и визуализацией.

## 🌟 Особенности

- **Vue 3** с Composition API
- **Главная страница** с 4 аналитическими графиками и таблицами топ артикулов
- **Страницы метрик** для детального анализа по каждому показателю
- **Страница артикула** с детальной информацией по выбранному товару
- **Интерактивные графики** с использованием Chart.js
- **Расширенная фильтрация** данных (артикул, регион, дата, категория, бренд) с сохранением состояния
- **Адаптивный дизайн** для всех устройств с поддержкой свайпа
- **Клиентская обработка** данных (фильтрация, сортировка, агрегация)

## 📊 Страницы приложения

1. **Главная страница (Home)** - 4 графика с общими показателями и таблицы топ артикулов:
   - Динамика продаж
   - Средний процент скидки
   - Отмены заказов
   - Региональная аналитика

2. **Страницы метрик** (`/metric/sales`, `/metric/discount`, `/metric/cancels`, `/metric/regions`) - графики и полные таблицы по каждому показателю

3. **Страница артикула** (`/article/:id`) - детальная информация по артикулу с таблицей показателей по датам

## 🛠 Технологический стек

- **Vue 3** - фреймворк
- **Pinia** - управление состоянием
- **Vue Router** - маршрутизация

## 🎯 Функциональность

### Аналитика и визуализация
- **4 основных показателя** на главной странице
- **Топ артикулов** с наибольшими изменениями по каждому показателю
- **Сравнение периодов** (текущая vs предыдущая неделя)
- **Визуализация изменений** с цветовыми индикаторами (зеленый/красный)

### Фильтрация
- Фильтр по артикулу (nm_id)
- Фильтр по региону (oblast)
- Фильтр по дате (dateFrom, dateTo)
- Фильтр по категории (category)
- Фильтр по бренду (brand)
- **Сохранение состояния фильтров** при переходе между страницами

### Навигация
- Переход на страницу метрики по клику на график
- Переход на страницу артикула по клику на строку таблицы
- Пагинация на страницах метрик

### Адаптивность
- **Горизонтальная прокрутка** таблиц на мобильных устройствах
- **Адаптивные графики** под разные размеры экранов
